# Frontend

React 19, Vite, Clerk, TanStack Query, React Hook Form and Tailwind form the
Tasker browser client. It is a single-page app; the Go API runs separately.

- [Entry points and routes](../../docs/frontend/README.md)
- [State, forms, cache and workflows](../../docs/frontend/state_and_workflows.md)
- [Local setup and troubleshooting](../backend/docs/local-development.md)
- [Whole-project learning guide](../../docs/overall_end_to_end/README.md)

Start with [src/main.tsx](src/main.tsx), [src/router.tsx](src/router.tsx), then
trace one page into a feature component and API hook. Some settings and bulk
controls remain placeholders; the workflow guide identifies them explicitly.
